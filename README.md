# AI Business Analyst

An AI-powered web app that automatically analyzes any business data file and generates a professional business report.

## What it does
- Upload any CSV or Excel file
- Automatically detects your data columns
- Generates charts and visualizations
- Uses AI to write a professional business report
- Download the report as PDF

## Built with
- Python
- Streamlit
- Pandas
- Groq AI (LLaMA 3.3)
- FPDF2

## How to run locally
1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Add your Groq API key to `.env` file: `GROQ_API_KEY=your-key-here`
4. Run: `streamlit run app.py`
